# Visionデバッグコマンド 前提・観測整理

## 1. 目的
- 本ファイルは、以下3コマンドの検証前提と観測結果を整理する。
- `A = ObservationOKCommand`
- `B = RelativeDriveOKCommand`
- `X = AbsoluteDriveOKCommand`

## 2. タグ前提
- 観測タグ: `id=1,2`
- 配置: 横並び
- 向き: 両方とも `theta = 225 deg`

## 3. ロボット姿勢・位置前提
- ロボット角度条件は2種類。
- 条件1: タグ角度 `theta` に対してロボット角度 `-theta`（タグ正対）。
- 条件2: タグの方を向かせる。

- ロボット位置は3種類。
- `P1`: タグ原点基準で `y = x` 上。タグ正対（この条件では `45 deg` 向き）。
- `P2`: タグ原点基準で `x < 0, y ~= 0` 付近。タグ正対。
- `P3`: タグ原点基準で `x ~= 0, y < 0` 付近。タグ正対。

## 4. RFカメラ実行時の観測

### 4.1 角度条件1（`-theta` で正対）
- `P1`
- `A`: 僅かに動く、または動かない
- `B`: 動かない
- `X`: 動かない
- `P2`
- `A`: 僅かに振動しながらタグ方向へ向かう
- `B`: 動かない
- `X`: 動かない
- `P3`
- `A`: 動かない
- `B`: 動かない
- `X`: 動かない

### 4.2 角度条件2（タグの方を向ける）
- `P1`
- 省略（角度条件1と同傾向）
- `P2`
- `A`: 動かない
- `B`: 動かない
- `X`: 動かない
- `P3`
- `A`: タグ方向へ向かう
- `B`: XY平面で見ると `-x, -y` 方向にドライブ
- `X`: 速度遷移が `Va(-,-) -> Vb(0,-) -> Vc(-,-)` のようになり、最終的にタグ角度に対して `-theta` で静止

## 5. LBカメラ実行時の観測

### 5.1 `P1`, `P2`, `P3` 共通傾向
- `A`: 前進
- `B`: `-omega` 方向に回転しつつ、僅かに `+x, -y` 方向へドライブ
- `X`: `-omega` 方向に回転しつつ、僅かに `+x, -y` 方向へドライブ（`B` より `-x, -y` 寄り）

### 5.2 位置依存メモ
- `P3` の `B` は、`P1` と `P2` より速度が大きい

## 6. 問題定義
- `A/B/X` の3コマンドが意図した動作になっていない。
- 挙動差が `RF` と `LB` で大きく、カメラ依存のズレが疑われる。

## 7. 表記メモ
- 元メモ中に `C` 表記があるが、文脈上は `X` とみなして整理した。
