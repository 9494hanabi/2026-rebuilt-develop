# AGENT Code Proposal Format Prompt

この chat では、コード提案を次の形式で出してください。

## 必須形式
1. 対象ファイル
2. 対象行
3. 操作種別
   - 追加
   - 置換
   - 追記
   - 新規作成
4. 差し込み位置または置換位置
   - `xx行目付近`
   - `〜〜のコードの中`
   - `〜〜の下`
   - `〜〜の上`
   の形で分かるように示す
5. 変更理由
6. 提案コード
7. 確認方法

## ルール
- ファイルの場所は分かりやすく示す
- 「どこかに追加」ではなく、どこに入れるかを明示する
- 置換なら、どのメソッドやブロックを変更後コードに差し替えるかを明示する
- コードは Haruta がそのまま反映しやすい単位で出す
- 既存ファイルの全文コードは出さない
- 変更点だけを変更ブロック単位で出す
- 提案は1変更ずつ順番に出す
- 未変更コードは、位置を見つけるための最小限だけ残す
- 可能なら、ファイル参照をクリックしやすい形で示す
- コード提案には見出しコメントを付ける
- コメントはコードの上に書く
- 変更前コードは原則として出さない
- イメージは「どのファイルの何行目付近の、どのコードの下や中にこれを入れるか」が一目で分かる形
- `コード理解タイム` のときは、ロジック変更より理解用コメント案を優先する

## 推奨見出し
- 対象ファイル:
- 対象行:
- 操作種別:
- 差し込み位置:
- 変更理由:
- 追加コード:
- 変更後コード:
- 反映後どうなるか:
- 確認方法:

## 悪い例
- `AutoVisionConstants にこれを足してください`

## 良い例
- 対象ファイル: `src/main/java/frc/robot/lib/constants/AutoVisionConstants.java`
- 対象行: `42行目付近`
- 操作種別: 追記
- 差し込み位置: `42行目付近` の `// 以下Piece detector pipelineの定数` の下
- 変更理由: Fuel cluster detection用の定数を追加するため
- 追加コード:
```java
// 以下Fuel cluster detectionの定数
public static final int ...
```
