# File Ownership

## Purpose
- 複数人開発でマージコンフリクトを避ける
- 担当ごとの編集範囲を守る

## Core Rule
- Haruta が編集できるのは、担当表記が `晴太`、`ハルタ`、`はるた` のファイルのみ
- `ひなた` など他担当が書かれているファイルは編集しない
- 担当表記がないファイルは、編集前に Haruta に確認する
- 新しく作るファイルの担当は、原則 `晴太` として扱う

## Priority Of Ownership Notes
- `専用`、`編集しないでください`、`できるだけ編集しない` のような強い制約がある場合は、名前があっても自動では編集しない
- `誰でも`、`共通` は「自由に編集してよい」ではなく、shared file として慎重に扱う
- `一旦晴太` のような暫定表記も、shared file の可能性があるので確認を優先する
- 名前と制約が混在していて判断が割れる場合は、Haruta に確認する
- `晴太` と書かれていても、同時に他担当向けの制約がある場合は、その制約を優先して確認する

## How To Check
- `import` 文の少し下あたりにある `// 担当` や `/* 担当 */` の表記を確認する
- 表記ゆれとして `晴太`、`ハルタ`、`はるた` は Haruta 担当として扱う
- 他の名前が書かれている場合は、編集対象から外す
- `誰でも`、`共通`、`一旦晴太`、`専用`、`編集しないでください` のような補足も同時に確認する
- 複数行コメントに制約が分散している場合は、名前だけで判断しない

## When To Ask Haruta
- 担当表記が見つからない場合
- 変更が必要なファイルが他担当だった場合
- 複数人の shared file で、担当ルールだけでは判断できない場合
- `誰でも`、`共通`、`一旦晴太` のような shared 扱いに見える場合
- `晴太` と他制約が同居していて、優先順位が曖昧な場合

## New File Rule
- 新しく提案するファイルは、基本的に Haruta 担当として考える
- 提案時は、ファイル先頭付近に担当コメントを入れる前提で考える
