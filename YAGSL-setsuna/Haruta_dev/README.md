# Haruta_dev

Haruta 個人用の Codex 運用ルール、補助 prompt、進捗資料を置くフォルダ。

## Read First
1. `HarutaAGENTS.md`
2. `workflow.md`
3. 必要な `policies/`
4. 必要なら `ROADMAP.md`、`PROJECT_OVERVIEW.md`、`FILE_MAP.md`

## Source Of Truth
- `HarutaAGENTS.md`: 最上位ルール
- `workflow.md`: 実際の進め方
- `policies/`: 詳細ルールの正本
- `prompts/`: 開始用テンプレート。正本ルールではない

## Main Files
- `ROADMAP.md`: 現在地と中期計画
- `PROJECT_OVERVIEW.md`: プロジェクト全体像
- `FILE_MAP.md`: 主要ファイルの役割と関連
- `CHANGELOG.md`: ルール変更履歴
- `WORKLOG.md`: 作業記録
- `AGENT_CODE_HISTORY.md`: AGENT がコード提案したときだけ残す履歴
- `reference/`: 公式情報の参照メモ

## Notes
- `AGENTS.md` とは別管理
- このフォルダ内のファイルは Haruta 個人用
- 新しいルールは、重複して複数ファイルへ書くのではなく、正しい正本へ寄せる
